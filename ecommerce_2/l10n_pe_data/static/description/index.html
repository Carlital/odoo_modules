SUNAT Tables & Catalogs (Peru)

Essential Master Data for Peruvian Localization

Overview

This module provides a comprehensive set of SUNAT (Superintendencia Nacional de Aduanas y de Administración Tributaria) catalogs and tables required for compliant electronic invoicing and accounting in Peru. It serves as a foundational data module for other Peruvian localization modules.

Included Catalogs

The module loads and manages the following SUNAT Catalogs (Anexos):

  • Catalog 01: Document Types (Tipo de Documento)
  • Catalog 02: Currency Codes (Tipo de Monedas)
  • Catalog 03: Unit of Measure (Unidad de Medida Comercial)
  • Catalog 04: Country Codes (Código de País)
  • Catalog 05: Tax Types (Tipos de Tributos)
  • Catalog 06: Identity Document Types (Tipo de Documento de Identidad)
  • Catalog 07: IGV Type (Tipo de Afectación del IGV)
  • Catalog 08: ISC Calculation System (Sistema de Cálculo del ISC)
  • Catalog 09: Credit Note Types (Tipo de Nota de Crédito)
  • Catalog 10: Debit Note Types (Tipo de Nota de Débito)
  • Catalog 12: Related Documents (Documentos Relacionados)
  • Catalog 15: Additional Elements (Elementos Adicionales)
  • Catalog 17: Operation Types (Tipo de Operación)
  • Catalog 51: Operation Types (Tipo de Operación - Code 51)
  • Catalog 53: Charges/Discounts (Cargos o Descuentos)
  • Catalog 54: Detractions (Bienes y Servicios sujetos a Detracciones)
  • Catalog 59: Payment Methods (Medios de Pago)
  • And many more (Catalogs 11, 14, 16, 18-24, 26, 27, 52, 55-58, 61)...

Key Features

Standardized Data

All data is aligned with the latest SUNAT specifications and Annex codes.

Easy Integration

Designed to be inherited and used by other localization modules for validation and selection.

Automatic Loading

Data is loaded automatically via CSV files upon installation.

Usage

This is a technical data module. Once installed, you can access the catalogs via the user interface if menu items are configured, or they are available in the background for other modules to reference (e.g., when creating an Invoice, selecting the "Document Type" will pull from Catalog 01).

Note: Ensure you have the `l10n_pe` module installed as a dependency.
