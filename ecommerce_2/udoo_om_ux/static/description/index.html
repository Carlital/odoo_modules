How does the Start Menu work?

↳ You can toggle the Start Menu using one of two methods: by clicking the square button located in the left area of the topbar or by pressing the keyboard shortcut alt+h.

↳ Here, you can customize the light and dark themes, language settings, manage bookmarks, all apps, and pinned apps. Pinned apps and bookmarks can be reorganized by long-pressing the app icon and dragging it to the desired position. The order of pinned apps corresponds directly to the app list on the sidebar. However, you also have the option to display all apps on the sidebar.

How does the Bookmark Manager work?

↳ There are multiple ways to create bookmarks:

  • Using "Bookmark current tab" command in Command Palette
  • Through Bookmark Manager popup using options: - "Bookmark Current Tab" for normal bookmark - "Bookmark Current Tab (General)" for pinned bookmark - "Bookmark Current Tab (Creation)" for quick create action
  • Using keyboard shortcut alt+k to open manager then select bookmark option

↳ Key features for managing bookmarks:

  • Lightning-fast navigation - bookmarks open instantly without page reload
  • Works with virtually any Odoo screen or view
  • Powerful fuzzy search to quickly find bookmarks using keywords
  • Batch management: Options to remove all bookmarks or just unpinned ones

↳ Organization & accessibility:

  • Bookmarks are automatically categorized into Quick Create and General sections
  • Pin important bookmarks to always appear at the top
  • Each bookmark has quick actions: delete, pin/unpin, open in new tab
  • Fast filtering through fuzzy search - find bookmarks even with partial or similar keywords

How does the Quick Create Actions work?

↳ Navigate to any form view you frequently create records (like Quotations, Contacts, etc), click the Bookmark Manager button and select "Bookmark Current Tab (Creation)" to add it as a Quick Create action.

↳ Your Quick Create actions will appear at the top of Command Palette under "QUICK CREATE" section with a "+" icon. Simply click or press Enter to instantly open a new creation form.

↳ This feature saves significant time by eliminating the need to navigate through menus - just press alt+k and select your Quick Create action to start creating new records immediately!

How does the Dual-tier Sidebar work?

↳ You can hide the sidebar using one of two methods: by clicking the interactive button located in the middle-left area of the sidebar or by pressing the keyboard shortcut ctrl+shift+left.

↳ To access the submenus, you can either click the interactive button (represented by three dots) on the respective menu item or right-click on the menu item itself.

↳ By default, the sidebar and horizontal menu will work together. However, if you wish to hide the horizontal menu while using the sidebar, you can customize this setting in the personalization options found in the user menu.

How does the Quick Pop-up view mode work?

↳ There are two ways to access this feature: by holding the shift key and clicking on an item on the Kanban board or by enabling it through the smart button located in the top right corner.

↳ To close the pop-up, you can either click the close button or use the esc key. To quickly save and close the pop-up, press ctrl+enter.

↳ The lifecycle of this feature will end when you exit the current Kanban board or disable it using the smart button.

How to control the position of the content side page?

↳ There are two ways to hide/show the chatter: through the interactive button located in the top right corner of the form view or by using the shortcut key ctrl+shift+right.

↳ On any form view, using the functions in the smart button, you can instantly change the position of the side page / chatter or even hide it globally.

↳ Press and drag the separator to adjust the proportion between the left anf right panels. The proportion will be reset to its initial state when you reload the page or end the session.

↳ For certain tablets with limited screen space, you may need to change the default position of the chatter. You can try changing it through the User Interface Size option in Appearance.

How are recently records processed automatically?

↳ This feature now only saves the access history of records in the detail view. To ensure system performance, the record history is synchronized only when you end your session (close the tab or browser).

↳ Duplicate records are automatically deleted at the end of each session, ensuring a clean and efficient record history.

What is Extended Creation Mode?

↳ Extended Creation Mode is a powerful feature that optimizes the process of creating multiple similar records. When enabled, it changes the behavior of the "New" button to automatically duplicate your last created record instead of opening an empty form.

↳ This feature is particularly useful when you need to create multiple records with similar information. For example:

  • Creating multiple quotations for the same product with different customers
  • Adding several contacts from the same company
  • Creating multiple inventory adjustments with similar items

↳ How it works:

  • Enable "Extended Creation Mode" in your form view
  • Create your first record with all the common fields filled
  • Click "New" - instead of a blank form, you'll get a duplicate of your last created record
  • Just modify the different fields and save - dramatically reducing repetitive data entry!

Does this theme support RTL layout?

↳ Absolutely, every detail, from individual characters to dynamic features like layout sizing and switching side page position, has been designed to work seamlessly in both RTL and LTR (Left-to-Right) directions.

↳ For additional information, if you are using the Odoo Community version, please ensure that the server has the RTLCSS library installed, refer to the official Odoo documentation: Note for languages using a right-to-left interface.
In case you encounter any issues, please follow these steps:

  • Step 1: Make sure RTLCSS is installed globally. Also, Node.js and NPM
  • Step 2: Restart Odoo and enable developer mode
  • Step 3: Click on the bug icon in the top bar, and select "Regenerate Assets Bundles"
  • Step 4: Switch to an RTL language (such as Arabic or Hebrew) and experience the change.
