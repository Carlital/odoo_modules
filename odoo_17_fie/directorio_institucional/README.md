# Directorio Institucional

Módulo para gestionar y mostrar el directorio telefónico institucional de ESPOCH.

## Características

- Extiende contactos (res.partner) con campos personalizados
- Campos adicionales: cargo institucional, unidad, teléfono institucional, extensión
- Etiqueta "directorio" para identificar contactos del directorio
- Snippet web con filtros dinámicos
- Búsqueda por nombre o apellido
- Filtrado por unidad institucional

## Uso

1. Ir a Contactos
2. Crear o editar un contacto
3. Asignar la etiqueta "directorio"
4. Completar los campos: cargo, unidad, teléfono institucional, extensión
5. Agregar el snippet "Directorio Institucional" a cualquier página web

## Formato de datos

Apellidos y Nombres | Cargo institucional | Unidad a la que pertenece | Teléfono institucional | Extensión telefónica
